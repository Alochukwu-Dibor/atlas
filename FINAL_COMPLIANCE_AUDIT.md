## Preserved functionality

- Department submission methods, multi-method submission, extracted/structured review, commitment comparison, evidence attachment and submission remain intact.
- Commercial review filters, progressive review detail, approve/edit/clarify/reject transitions and audit history remain intact.
- Project search/filter/detail, objective drill-down, decisions, recommended-action authoring, executive assignment and action-progress workflows remain intact.
- Existing role switching, cycle/context controls, deterministic demo scenarios, exports and legacy route redirects remain intact.

## Known unmet or partially met requirements

| Missing or partial requirement                                                                                               | Why it was not fully implemented                                                                                                                                              | Exact file or screen affected                                                                        | Recommended next step                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Generated Outputs do not create real PDF, DOCX or XLSX binaries; Export uses the browser print surface.                      | The source documents explicitly define publishing/export and external systems as deterministic prototype simulations, and this repository has no production document service. | `OutputsPage` in `src/pages/ArchitecturePages.tsx`; `/outputs` and `/executive/outputs`              | Add fixture-driven document renderers and downloadable synthetic files when export-format acceptance criteria are approved. |
| Meeting and Governance demonstrates one linked Commercial Review rather than all nine meeting types listed in product scope. | The product document asks the prototype to demonstrate the relationship and explicitly excludes a full calendar/transcription product.                                        | `meetingRecords` in `ATLAS_MOCK_DATA.json`; Decisions → Context in `src/pages/ArchitecturePages.tsx` | Add one fixture for each meeting type only when those additional demo scenarios are required; keep them contextual.         |
| Safari and Edge were not executed in this environment.                                                                       | The available automated browser surface was Chromium-based.                                                                                                                   | All application routes and `src/styles.css`                                                          | Run the same role/route and 390 px responsive checklist manually in current Safari and Edge before production handoff.      |
| A comprehensive WCAG audit with axe and assistive-technology testing was not performed.                                      | The requested scope was accessibility basics and no dedicated audit dependency or screen reader was available.                                                                | All screens, especially dense tables and drawers                                                     | Add automated axe checks, VoiceOver/NVDA passes and contrast verification before productionisation.                         |
